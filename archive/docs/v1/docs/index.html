No minified bundles. No 5,000-line JSON reports. Run one simple command, and all authentic upstream Git repositories behind any npm package are shallow-cloned as sibling folders right in your workspace.

$ npx @keshavsoft/npm-source-explorer <package-name>

The Story Behind The Tool

When auditing, learning, or debugging, developers don't want to dig through bundled code in node_modules.

📦

Node Modules Is A Maze

Bundled code in node_modules is stripped of original comments, missing test suites, unreadable, and has zero Git history.

🔍

Automated Discovery

npm-source-explorer inspects the target package and recursively follows every dependency edge to discover the real GitHub/Git repo behind each one.

🗂️

Clean Sibling Folders

Every distinct repository is shallow-cloned directly into your current directory as a sibling folder. Open your IDE and search across the actual code.

Lean V3 Engine

Zero legacy bloat. Under 7 KB across 3 single-purpose modules.

1. RESOLVE

Arborist Discovery

Recursively inspects dependencies in an isolated temporary OS folder and extracts declared Git URLs.

2. NORMALIZE

Repository Cleaning

Converts varied repo configurations (git+https, SCP SSH, shortcuts) into canonical HTTPS endpoints.

3. CLONE

Sibling Cloner

De-duplicates repositories and shallow-clones (--depth 1) them as clean sibling folders in your workspace.

Terminal Quickstart

Open an empty folder and run:

Terminal

# Create an exploration folder

mkdir audit-react && cd audit-react


# Download and clone all upstream source repositories

npx @keshavsoft/npm-source-explorer react
