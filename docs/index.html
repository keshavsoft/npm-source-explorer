One command to recursively trace dependencies and download all upstream Git repositories as sibling folders in your workspace.

$ npx @keshavsoft/npm-source-explorer <package-name>

The Story

When auditing, debugging, or learning from open-source libraries, looking into node_modules is painful. The code is bundled, minified, stripped of original comments, missing unit tests, and has no commit history.

What developers actually want is the original source code.

Instead of searching for 20 different repository URLs on GitHub, you run one command in an empty folder: 

mkdir audit-json && cd audit-json
npx @keshavsoft/npm-source-explorer json-renderers

How It Works

  • Recursive Discovery: Reads the package and recursively inspects every dependency down the tree in clean isolation.
  • Repository Resolution: Finds the authentic GitHub or Git repository URL declared by each package's authors.
  • Sibling Cloning: Shallow-clones (--depth 1) each unique repository directly into your workspace side-by-side as siblings.
  • Fail-Safe Protection: Each clone operation includes a 25-second timeout and disables interactive terminal prompts so private or slow repositories never freeze your terminal.

Your Workspace Result

After the command finishes, all repositories sit side-by-side as peers in your folder. Open your editor (code .) and search across the actual un-minified code: 

my-workspace/
├── json-renderers/                       <-- Root package source with commits & tests
├── json-renderers-build/                 <-- Sibling dependency repository
├── json-to-spec/                         <-- Sibling dependency repository
├── json-transformer-funcs/               <-- Sibling dependency repository
├── json-transformer-funcs-primitive/     <-- Sibling dependency repository
└── json-transformer-funcs-one-dimension/ <-- Sibling dependency repository
