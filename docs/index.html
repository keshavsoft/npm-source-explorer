$ npx @keshavsoft/npm-source-explorer analyze <package>

The Story Behind The Tool

When you install an npm package, you inherit a sprawling graph of transitive dependencies written by hundreds of different authors. How do you verify what is actually running?

⚠️

The Dependency Black Box

An npm tarball published to the registry is not guaranteed to come from a real or healthy Git repository. Repositories can be deleted, private, unmaintained, or omit repository fields altogether.

🔍

Git Tag & Version Mismatches

Does version 2.4.1 on npm have a corresponding Git tag v2.4.1 in the source repository? A missing or diverted tag is an immediate signal to investigate potential supply chain drift.

📥

Local Source Auditing

Reviewing minified bundles in node_modules is painful. npm-source-explorer automatically gathers distinct Git URLs across the entire dependency graph and shallow-clones them locally.

Two Modular Engines

Designed for speed, modularity, and programmatic integration in CI/CD pipelines.

V1 ENGINE

Dependency Graph Traversal

Uses @npmcli/arborist to simulate clean package installation inside isolated OS temp directories without touching your current environment.

  • Extracts complete resolved node trees and directed relationship edges.
  • Detects unresolved packages and invalid dependency constraints.
  • Normalizes messy repository URL permutations (git+https, scp shortcuts, SSH).
  • Exports structured machine-readable JSON for downstream pipelines.
V2 ENGINE

Repository & Tag Verification

Takes the graph generated by V1 and tests external repository validity, version tags, and clones sources.

  • Performs asynchronous HTTP checks on repository homepages and endpoints.
  • Runs remote Git checks (git ls-remote --tags) for matching release tags.
  • Identifies distinct, de-duplicated repositories across all dependencies.
  • Performs shallow Git clones (--depth 1) directly into your designated directory.

CLI Commands & Reports

Zero configuration required. Execute directly with npx:

Terminal — npm-source-explorer

# 1. Resolve and export full dependency graph report

npx @keshavsoft/npm-source-explorer analyze express --out ./express-graph.json


# 2. Check repository reachability and Git version tags

npx @keshavsoft/npm-source-explorer verify react --out ./react-verification.json

✔ Checked 28 package instances: 28 reachable, 27 exact tags matched.


# 3. Clone all distinct source repos into a target folder

npx @keshavsoft/npm-source-explorer clone lodash --clone-dir ./audited-sources

✔ Cloned 1 unique repository to ./audited-sources/lodash

Programmatic Node.js ESM API

app.js — ESM Import
import { analyzeDependencies } from "@keshavsoft/npm-source-explorer/v1"; import { verifyRepositories, cloneRepositories } from "@keshavsoft/npm-source-explorer/v2"; // Analyze dependency tree in isolation const report = await analyzeDependencies("express"); // Verify Git release tags & reachability const verified = await verifyRepositories(report); // Clone all upstream repos await cloneRepositories(report, "./cloned-sources");
