Give it any package name. It recursively traces all dependencies, discovers every authentic upstream Git repository, and downloads them side-by-side as clean sibling folders right in your workspace.

$ npx @keshavsoft/npm-source-explorer <package-name>

The Story: Why We Built This

When learning from, debugging, or auditing third-party code, reading node_modules is a nightmare.

📦

The Node Modules Maze

Bundled packages in node_modules are minified, transpiled, stripped of original comments, missing unit tests, and lack Git history.

🔍

Recursive Discovery

It reads the package, recursively follows every nested dependency edge, and locates the authentic GitHub or Git repository declared by its authors.

🗂️

All Sibling Repositories

Every distinct repository is downloaded side-by-side into your current directory. Open your editor and search through the actual, un-minified code.

How It Works in 3 Simple Steps

Zero configuration required. Pure dependency discovery and shallow Git cloning.

STEP 1

Recursive Traversal

Inspects the target package and recursively follows every dependency down the entire tree in clean isolation.

STEP 2

Repository Resolution

Extracts and normalizes the declared GitHub / Git repository URLs for every unique package found.

STEP 3

Sibling Git Cloning

Performs fast shallow clones (--depth 1) directly into your workspace as clean sibling folders.

Real Terminal Execution

Terminal — PowerShell / Bash
