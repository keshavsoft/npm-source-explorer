The Decoupled Ecosystem

A clear look at the three dedicated repositories, how they relate, and how they compose together to discover, resolve, and clone upstream open-source code.

The Architectural Story: Why Decouple?

Originally, discovering dependency trees and cloning Git repositories were combined in a single package. But examining the pipeline revealed two distinct, powerful responsibilities:

  • Discovery & Provenance: Takes a package spec, builds the tree via Arborist in an isolated sandbox, normalizes Git URLs, and produces a verified Source of Truth manifest. Zero Git CLI required.
  • Workspace Builder: Takes any list of Git repositories, shallow-clones them as sibling folders, terminates hung child processes with taskkill, and suppresses interactive prompts. Zero npm required.

By separating them into dedicated micro-repositories, developers can use each tool on its own or orchestrate them seamlessly through the flagship suite.

The 3 Repositories

1. npm-repo-resolver

Dependency Tree & Git Provenance Engine

The Source of Truth

Recursively traces any npm package down its entire transitive dependency tree and extracts canonical upstream Git repository remotes. Outputs an immutable, deduplicated JSON manifest without cloning files. 

# Quick CLI Usage:
npx npm-repo-resolver express

# Formatted Table Output:
npx npm-repo-resolver express --table

# Count Unique Repositories:
npx npm-repo-resolver express --count
📦 npm Package (v1.0.1) 🐙 GitHub Repository 🌐 Live Documentation
2. git-sibling-cloner

Fail-Safe Sibling Workspace Builder

The Builder

Takes any list of Git repositories (from npm, GitHub orgs, Cargo, Python, or internal manifests) and shallow-clones (--depth 1) them side-by-side as siblings. Armed with 25s timeouts and Windows taskkill tree-killing. 

# Quick CLI Usage:
npx git-sibling-cloner manifest.json ./workspace

# Piped from Standard Input:
cat manifest.json | npx git-sibling-cloner ./workspace
📦 npm Package (v1.0.1) 🐙 GitHub Repository 🌐 Live Documentation
3. @keshavsoft/npm-source-explorer

Flagship Suite & Orchestrator (V9)

The Suite

The flagship developer tool that orchestrates both npm-repo-resolver and git-sibling-cloner in a single seamless command. Turns any package into a peer-to-peer sibling workspace ready for code auditing in your editor. 

# One-Command Full Exploration:
npx @keshavsoft/npm-source-explorer express

# Custom Workspace Folder:
npx @keshavsoft/npm-source-explorer react ./react-sources

The UNIX Pipe Story

Because npm-repo-resolver writes its progress to stderr and pure JSON to stdout, and git-sibling-cloner reads from stdin, you can pipe them directly across your terminal: 

# Composing the two independent micro-tools via UNIX pipes:
npx npm-repo-resolver express | npx git-sibling-cloner ./my-sources

Or run the flagship all-in-one command: 

npx @keshavsoft/npm-source-explorer express
